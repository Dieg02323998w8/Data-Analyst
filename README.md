# 📊 Analista de Datos | Data Analyst

## 👨‍💻 Acerca de mí

Estudiante de Ingeniería de Sistemas de la Universidad del Pacífico, con conocimientos en programación, bases de datos, estadística y análisis de información. Interesado en transformar datos en información útil para comprender situaciones, identificar patrones y apoyar la toma de decisiones.

Cuento con conocimientos en **Python, R, RStudio, Octave, MySQL y SQL**, así como fundamentos de matemáticas aplicadas, modelado de datos y análisis estadístico.

## 🎯 Perfil profesional

Orientado al análisis, procesamiento e interpretación de datos, con capacidad para organizar información, realizar consultas a bases de datos, aplicar métodos estadísticos y desarrollar modelos matemáticos para identificar tendencias y relaciones entre variables.

Mi formación en Ingeniería de Sistemas me permite integrar conocimientos de programación, bases de datos y pensamiento analítico para abordar problemas mediante soluciones basadas en datos.
